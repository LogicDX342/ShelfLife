Keep your desktop and downloads folders tidy. Automatically.

ShelfLife is a lightweight Windows utility that treats specified folders as temporary staging areas. Files decay safely into the system Recycle Bin after a duration you decide.

Customizable Rules

Create automation rules based on file extensions, size, glob patterns, or source origins. Preview matches safely before activating them.

Decay States

Files transit from Fresh to Stale, then Decaying, and finally to the Recycle Bin. You define the timelines.

Safe & Reversible

Nothing is deleted permanently. Files are moved to the system Recycle Bin, and all actions are fully undoable from the Activity Log.

Zero Resource Waste

Built on Tauri and native Windows file system watchers, it sits silently in the system tray consuming negligible memory.
